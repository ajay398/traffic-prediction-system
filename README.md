# 🚦 AI Traffic Prediction System

An industry-style Machine Learning and FastAPI application
for predicting traffic volume and congestion levels.

## 🚀 Features

- Traffic volume prediction
- Traffic congestion classification
- Weather-based traffic analysis
- Time-based feature engineering
- Machine Learning model comparison
- REST API
- PostgreSQL database
- Docker support
- Automated testing
- CI/CD with GitHub Actions

## 🛠️ Tech Stack

- Python
- FastAPI
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- PostgreSQL
- SQLAlchemy
- Docker
- Pytest
- GitHub Actions

## 📂 Project Structure

```text
app/        → FastAPI application
ml/         → Machine Learning pipeline
tests/      → Automated tests
notebooks/  → Data Science experiments

## 📊 Dataset

This project uses the Metro Interstate Traffic Volume dataset
from the UCI Machine Learning Repository.

The dataset contains traffic volume observations along with
weather and time-related information.

### Main Features

- Holiday
- Temperature
- Rainfall
- Snowfall
- Cloud coverage
- Weather condition
- Date and time
- Traffic volume

### Target

`traffic_volume`

UCI Machine Learning Repository:
